# 沙雕漫零成本制作管线（v10）

> 路线：静态底图+镜头动效为主、全场只留2-3个真动态镜头的Q版沙雕漫。现金成本≈0（订阅内生图+免费TTS+免费剪辑）。剧本用你自己的现成剧本（本仓库只放管线工具，不含剧本内容）。

## 一、定位

- **画风**：Q版沙雕漫——自创Q版角色（沙雕脸+夸张表情），用自创角色保版权差异化，不直接搬现成表情包IP
- **成本**：现金≈0（生图走订阅额度、TTS免费、剪映免费）
- **节奏**：一集约110秒12镜，每镜以静态图+镜头动效为主，全场只留2-3个动态镜
- **对标**：抖音沙雕修仙/沙雕动画系列——验证过的流量赛道

## 二、零成本管线（五步）

### 第1步：角色定妆+表情包（生图，一次性）
每角色生成：定妆全身图1张 + 三表情（得意/慌张/震惊）各1张。提示词模板：
```
Q版沙雕漫画风格，二头身大头小身比例，夸张表情。竖屏。
[角色名]：[外貌+服装+标志性随身道具一句话]。
表情：[得意/慌张/震惊三选一，描述具体：如嘴角咧到耳根/冷汗三根/眼珠瞪圆弹出]。
背景纯色，无文字无水印。
```
一集约4个角色×4张=16张，批量一晚出完（见 `../批量生图/`）。

### 第2步：场景图（生图，一次性）
4-5张全景。沙雕漫=高饱和+粗线条，与写实光影路线完全相反。

### 第3步：分镜转化
每镜拆成：**底图（角色+场景合成）+ 镜头动效 + 台词字幕 + 音效**。
合成方法：剪映贴纸式拼合（角色PNG叠场景图）或生图直接出"角色在场景中"整图。每镜1-2张静态底图即可，12镜≈20张图。

### 第4步：动态镜（全场仅2-3个）
只给名场面（重击/变形/吞吐类自带笑点的动作），6秒、无台词、≤2镜头。写提示词沿用视频提示词规范（时段/场景/道具特征/人物锚点/负面清单全带）。

### 第5步：组装
- TTS：每角色锁定一个音色全剧复用（见 `../配音/`）
- 动效：缩放推近（情绪重音）/左右微摇（慌乱）/震屏（重击落下）+拟声字"哐！""嗡——"
- 卡点：重击=重音效+震屏；爆点分布与剧本节奏对齐
- 发布：勾AI声明+合集连载+结尾追更钩子

## 三、验收清单（每镜过）

- 表情包感：每镜至少一个夸张表情/姿势（沙雕漫的灵魂）
- 音效密度：每5秒至少一个音效
- 台词字幕与剧本一字不差（同一份台词源派生，不手抄两遍）
- 角色脸一致（同一角色全用同一套定妆图拼）
- 现金成本=0

## 四、执行顺序

1. 批量出角色定妆+表情（免费额度）
2. 出场景图+逐镜底图
3. 2-3个动态镜+剪映组装E01
4. 发布→看5秒完播/时长→迭代E02
